# File Cleaner & Merger

Καλώς ήρθες στο έργο **File Cleaner & Merger**!  
Ένα cross-platform εργαλείο καθαρισμού και συγχώνευσης αρχείων, σχεδιασμένο για σταθερότητα, ταχύτητα και φορητότητα.

---

## 📦 Χαρακτηριστικά
- Συγχώνευση πολλών αρχείων κειμένου σε ένα.
- Καθαρισμός διπλότυπων ή άχρηστων γραμμών.
- Υποστήριξη UTF-8.
- CLI και GUI (Kivy).
- Εύκολη ενσωμάτωση σε pipelines ή αυτοματισμούς.
